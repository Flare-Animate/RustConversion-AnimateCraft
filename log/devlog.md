## 2026-10-10 — M0.1: core editing fixes (user report: panel dead, frames unselectable, can't delete)
- Root causes: no frame-selection model at all; Delete edited a new keyframe instead of the span holding the object (object reappeared on other frames); window opened at 1440x880 logical px, which overflows the screen at 125–150% Windows scaling (right panel/timeline off-screen); paste never fired (egui only emits Paste when the OS clipboard has text); drags anchored at drag-detect point, not press origin (marquee/rect short by a few px).
- New `frames` module (pure, tested): insert/remove frames, convert to (blank) keyframes, clear keyframes, clear frames, tween on range, copy/paste/move frames with Animate semantics (moving a keyframe stretches neighbouring spans).
- Editor: multi-selection (click, shift-click, marquee, select all), delete from owning keyframe (both ends of a tween), cut/copy/paste/paste-in-place/duplicate, break apart, multi-object convert to symbol, layer reorder, library rename/duplicate/delete/type.
- App split into stage/panels/timeline modules; window starts maximised; stage + timeline take focus from text fields so shortcuts always work; right-click menus on stage, frames and library; library drag-to-stage.
- 24 tests green. UI scenarios exercised under Xvfb via tools/ui_drive.py: frame click/range/context menu, keyframe drag, click+Delete, marquee+Delete, Ctrl+Z, typed W/alpha, rotate, stroke toggle, library delete with confirm, library drag-to-stage, copy/paste/cut.
- Still open: command registry/MCP; merge drawing; rulers/snapping; FLA import; real file dialogs (rfd).

## 2026-10-11 — Phase 3 of the gap analysis (the Merge Drawing engine)
- Pushed Phases 1+2 to GitHub first (user confirmed).
- `ac-core/src/merge.rs`: `MergeShape` = disjoint fill regions (one connected area each, outer + holes) + stroke edges, built on i_overlay 9 (MIT, pure Rust). Fills cut fills and strokes under them; touching same-paint regions union; lines slice fills (`slice_by`) and split crossing lines; erase/paint with modes; Faucet; hit test, connected selection; extract by parts / rect / lasso; `merge_in` for drops; bucket fill of areas enclosed by lines with a gap tolerance (strokes thickened by the gap, holes of the union, grown back); optimise/smooth/straighten; morph for shape tweens; edge bending (chain between corners, resampled so shared fill/stroke geometry bends together, smooth falloff) and corner drags; Combine Objects booleans.
- Model: `ElementKind::Canvas` (the layer's merge shape, kept at index 0 of a keyframe) with a `float` = the selected piece, stored in the document so undo, autosave and rendering just work; saving commits floats in a copy. Shape gained `primitive`, `stroke_style`, `bitmap_fill`, `rig`; DrawItem carries stroke style and a bitmap pattern; renderer + SVG export draw dashes/caps/joins.
- `ac-core/src/rig.rs`: shape armatures (bones inside one shape, linear-blend skinning, CCD IK, Bind overrides, tweened poses); shapes are densified when they get their first bone so they can bend.
- Editor: merge draw/paint/erase/faucet/bucket/ink, part selection with floats (move/transform/delete/recolour through the existing paths), marquee/lasso cuts, detach floats for group/symbol/copy, paste onto the shape as a float, Break Apart drawing objects → merge shape, merge selection → drawing object, combine_objects, shape_cleanup, rig add/IK/bind/clear.
- App: Merge Drawing default with J toggle; drawing tools route through `place_shape`; Selection picks/moves/bends merge parts; dot-screen over floating selections; brush/eraser modes, Faucet, bucket gaps, Lock Fill in Tool properties; Modify ▸ Combine Objects / Shape; Rectangle/Oval Primitive and Bind tools; Properties for shape selections, primitives, stroke style, bitmap fill, shape bones.
- 25 new script commands (drawing.mode, merge.*, selection.combine/shape/stroke_style/bitmap_fill, draw.*_primitive, shape_bone.*).
- Bugs found while testing: a derived `Default` gave StrokeStyle zero dash lengths (dashes looked like a grey line) — manual Default + regression test; a rectangle's four points can't bend with bones — shapes are now densified on their first bone; transform handles grabbed bone drags — shape bones now take priority with the Selection tool.
- Tests: 83 (59 core incl. merge engine, merge workflow through the editor, combine objects, rig, primitives; 13 render; 11 scripting). Xvfb runs: overlapping merge shapes + lift/drag of a fill split by an outline, edge bend, marquee cut + move, bucket into an outline, eraser swath, shape bones bending a bar. CLI run of every new command rendered to PNG.
